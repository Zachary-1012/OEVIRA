# OEVIRA product core

Python product API, domain modules and durable workers belong here. See
../docs/ARCHITECTURE.md for workspaces, sources, results, versions, task state,
acquisition/browser, AI, document/media and runtime boundaries.

Implementation is present in `oevira/`, with isolated tests in `tests/`. It is
partial and does not establish complete domain workflows or production readiness.
Use the project interpreter and repository-rooted commands in
[the development guide](../scripts/README.md); do not run the former workspace.
