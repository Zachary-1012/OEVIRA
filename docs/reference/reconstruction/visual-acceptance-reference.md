## 审阅方式

根负责原创视觉决定，不把配色、构图、动效审美交给子代理。开发时先在真实专业工作中呈现可操作界面，审阅字体层级、密度、内容主次、控制关系、原生作品质感和品牌辨识；不把“有植物/像素/材质”当质量。官网叙事与应用操作分别审，不套同一模板。

选代表性工作面、真实内容规模、系统状态和关键分支，加按WCAG-EM方法的随机样本，检查完整流程。不同作品专业差异必须覆盖：表格/地图/演示/时间线不互相代验。用户任务检验有效性、总耗时和主观负担；记录帮助次数、误操作、修复成本及未完成原因，不能只记成功者。独立用户与专业人员评审用于验证可理解与可交付；自动规则、截图对比、设计文件只是其中证据。

所有检查同时服务全功能：发现复杂场景困难时修操作与实现，不删除功能，不以“高级功能以后再说”让当前界面显得干净。
