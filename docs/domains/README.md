跨域共用身份、来源、权限、任务和版本，不复制专业规则；领域不能被通用Work/Material/Artifact名称吞掉。[专业协议](../API.md)逐域落实输入、操作、结果和消费者，保现有基础接口的明确边界。实现缺失不削需求，研究证据不代运行与专业验收。

## 内容生态的跨域承接

用户/官方作品、视频创意与方案模板、经验复用按完整规格§20纳入；由上述创作、交付、身份/权限、媒体、任务和知识职责共同承担，不替换26领域，也不把领域总数当原子需求完成率。具体协议见[API](../API.md)，前端执行见[执行附件](../FRONTEND-EXECUTION.md)，最终验收见[验收](../ACCEPTANCE.md)。
