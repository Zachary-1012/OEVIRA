# 专业领域唯一职责入口

本目录是完整产品规格的唯一专业方法Owner。各方法、对象、输入、步骤、适用条件、反例、结果、修改、异常、恢复和验收必须在所属正文中说清；不得要求开发者查历史研究、矩阵、Review或外部附件来补基本定义。

| 唯一文件 | 唯一职责 |
|---|---|
| [business.md](business.md) | 商业主体与经营关系、市场/消费者、财务预算、品牌策略、合作履约、活动排期、实验评价、舆情事件、决定行动复盘 |
| [creative.md](creative.md) | 独立研究、原创内容、Word/PPT/Excel/PDF/HTML生成与局改、完整视频、完整播客、语言声音、模板/作品/经验生态及跨成果交付 |
| [intelligence.md](intelligence.md) | 通用检索、双浏览器与上下文、采集、持续监测、自研行业AI、检索排序、记忆、数学、Skills/MCP/插件、权限与恢复 |

跨域身份、来源、权限、任务和版本由既有统一Owner承担，不复制第二套系统。产品行为以docs/PRODUCT-SPEC.md为准，视觉与空间以DESIGN.md为准，前端步骤以docs/FRONTEND-EXECUTION.md为准，系统/API/验收分别以各自唯一权威文件为准。

开发执行者只负责编码、兼容、性能、调试和按合同验收；不得重新研究产品范围、专业方法或交互决策。真正缺失的实现细节只作定点技术核验，不改变产品定义。
