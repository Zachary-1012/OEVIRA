# 完整领域合同

本目录承接[完整产品规格](../PRODUCT-SPEC.md)的全部专业工作，合同定义用户输入、实际处理、可编辑结果、修改保全、消费者及失败恢复。编号只用于追溯，不是用户操作流程或能力上限。

| 文件 | 完整职责 |
|---|---|
| [business.md](business.md) | 客户/主体/品牌/场内经营；经营市场；财务预算；品牌策略；创作者合作；活动内容排期；实验归因；事件响应；决定行动复盘，共9域 |
| [creative.md](creative.md) | 独立研究；原创跨媒介；Word；PPT；表格；PDF；完整视频；完整播客；语言声音；跨成果修订交付，共10域 |
| [intelligence.md](intelligence.md) | 主动采集；受控浏览官方登录；持续监测；行业AI；知识记忆纠错；运行权限恢复；既有扩展，共7域 |

跨域共用身份、来源、权限、任务和版本，不复制专业规则；领域不能被通用Work/Material/Artifact名称吞掉。[专业协议](../API.md)逐域落实输入、操作、结果和消费者，保现有基础接口的明确边界。实现缺失不削需求，研究证据不代运行与专业验收。

## 内容生态的跨域承接

用户/官方作品、视频创意与方案模板、经验复用按完整规格§20纳入；由上述创作、交付、身份/权限、媒体、任务和知识职责共同承担，不替换26领域，也不把领域总数当原子需求完成率。具体协议见[API](../API.md)，前端执行见[执行附件](../FRONTEND-EXECUTION.md)，最终验收见[验收](../ACCEPTANCE.md)。
