## 1. 产品目标与共同工作模型

寰意服务媒体、广告、品牌营销与商业运营行业，完整支持商业运营团队、品牌与代理机构、独立研究者与创作者。三类用户共享身份、来源、资料、成果、权限与恢复，各专业工作保留实际业务对象、计算方法和直接编辑能力。客户、法律/商业主体、集团、品牌/子品牌、商业项目/场所、场内商户/门店、产品/SKU、账号与工作委托不是通用标签；临时工作可不绑定主体，不取消主体经营领域。

共同工作链为目标和必要材料 → 任务内发现与取得来源 → 核对、专业计算与判断或原创创作 → 可编辑成果 → 客户意见与局部修订 → 成套交付 → 实际行动、观察和再次使用。研究、文稿、视频和播客各自可独立使用，也可承接客户工作；用户能从空白、原件或任何已有阶段继续。无需为简单任务填齐所有业务档案、选择论文或逐步调度内部工具。

AI 与人工调用同一专业操作。基础资料、计算、编辑、播放、保存、导出和恢复不依赖外部模型API、AI推理或训练用GPU；AI 专属功能通过真实推理增强相应对象，分别评价效果。全产品的简化减少重复取数、重复录入、上下文搬运和修改损失，不删除专业能力，不用阶段实现边界代替完整需求。

## 2. 架构原则与部署形态

采用模块化单体与独立重任务 Worker。产品 API 负责边界校验和领域用例调用，专业规则由对应领域实现，持久化使用短事务；一个或多个同版本 Worker 领取已持久化的采集、研究、渲染和导出任务。模块共享同一数据库和文件存储，但各自拥有数据写入规则与领域 API。Worker 是执行形态，不是第二个业务服务或第二份真相。

当前采用模块化单体，不为结构整理引入 Redis、Kafka、Temporal、独立搜索集群或新的云端模型服务；既有用户通用模型接口按§13保留。任务表承担可恢复的工作领取与状态持久化；短事务写业务数据，网络采集和媒体渲染均在事务外执行。文件只由统一 Artifact Store 管理，业务库保留授权、版本、哈希和可恢复定位。

前三种运行形态共用同一产品服务与领域逻辑：① Windows 本机模式把 API、Worker、数据库和文件放在同一受保护数据根，本地工作不要求注册云账号；② Web 连接本机核心，页面由正在运行的本机服务提供，不能把纯静态页面称为完整产品；③ Web/Windows 连接用户控制的服务端，同一 Workspace 由唯一服务端负责权威持久化与 Worker，多用户通过 API 共用该端。SQLite 是首期单节点关系数据库，使用短写事务和 WAL；并发容量超过实测能力时，先基于负载证据另立数据库升级决策，不静默引入第二数据库。数据库迁移必须保全历史版本和文件引用。

一个 Workspace 同一时间只有一个权威运行端，客户端选择并显示该端；不得同时将本机数据库与云端/服务端数据库作为可写主库，不做首版双向数据库同步。远端连接断开时，客户端保留可识别为“本机草稿”的未同步文本、对象及媒体工程编辑和 base_version；它不是已保存的服务端成果。重连后先读回远端版本，用户可比较并显式应用或另存新版本；冲突不得静默覆盖。持续监测只在该 Workspace 权威端的获授权 Worker 实际运行期间执行。本机休眠、关机、用户停止服务或部署主机不可用时，任务进入可恢复的暂停/中断状态，不宣称仍在监测。云主机、托管、域名、付费资源和生产部署均需另行选择并批准。

## 3. 服务端边界与模块责任

下表为同一产品核心内的职责，不是独立服务、独立数据库或要求先创建的空目录。模块足够小时可以保持简单文件；拆分以真实职责、调用关系和复杂度为依据。

|---|---|---|
| Core / Identity / Workspace | 用户、工作区、客户范围、成员、角色、会话、来源用途、文件与版本共同机制 | 服务端从已核身份生成上下文；选择主体/客户不授予权限 |
| Work | 用户目标、约束、输入引用、当前成果、未完意见与可继续的工作 | 可引用多种专业对象；不把长期监测变成无限聊天任务 |
| Business | 客户委托、主体/品牌/场内经营、市场/消费者、财务预算、策略、合作、活动/内容排期、实验、事件、决定/行动/结果 | 九领域行为见业务合同；不另造通用CRM、财务记账或ERP，不借这些边界删除原业务行为 |
| Acquisition | 一套任务发现、选路、取数、原生字段、解析、去重、分页与来源合同 | HTTP/Feed/结构化/浏览路线共用任务、权限、来源与恢复；不按平台复制底座 |

| Material / Research / Claims | 原件、解析覆盖、页段表时码、问题/比较、引文、反证、主张与专业研究 | 索引是可重建派生；不改原件，不把模型输出变事实 |

| Media | 前期脚本/分镜/前采、素材、录制/take、时间线、多轨/图层、声音、字幕、预览、渲染与工程交换 | 视频与播客共享时钟/媒体基础，保各自完整制作与精修行为 |
| Intelligence | 既有通用模型接口、自研小模型、全业务智能、未来训练蒸馏；知识与分层学习 | 不拥有第二套业务规则、权限或事实；不以通用接口替代小模型或真实业务消费者 |
| Artifact / Delivery | 成果身份、不可变修订、对象差异、评论、批准范围、交付批次与增量重交 | 正文引用各领域对象，不压平为一种JSON；导出与外部发送分别处理 |

调用使用稳定对象身份和版本化的请求/响应。用户、工作区/客户、用途、对象与父版本、允许动作和源版本贯穿人工、AI、Worker、文件、检索及导出。UI/API不另行实现相同业务判断。目录、接口、消费者和测试随一项真实能力同时更新。[API合同](API.md)逐项规定九个业务、十个创作、七个系统智能领域的输入对象、操作、输出及直接消费者；其现有本地基础路由单独列明，不能作为完整协议上限。

## 4. 多用户、工作空间与权限

工作空间是租户隔离单位。用户可加入一个或多个工作空间；成员关系记录角色、状态和授权时间。工作、材料、来源身份、任务、Artifact、导出和存储对象均带工作空间归属。任一读、写、下载、取消、恢复操作都须同时验证当前用户成员资格、资源工作空间和动作权限；只凭不可猜 ID 不构成授权。

客户端提交的 tenant/workspace ID 只能选择用户有权进入的空间。服务端验证后生成请求上下文；异步任务将该已验证上下文绑定在可信任务记录中，Worker 执行前重新验证任务目标和仍然有效的成员/来源授权。跨租户资源按不可区分的未找到响应拒绝，避免 IDOR 泄漏。

本地首次启动使用数据根中的一次性 bootstrap capability 建立本机用户和工作空间。Capability 不写日志、URL 查询、源码或提交记录；本机授权完成后作废。这个初始化入口不是任意远程注册。远程协作身份由已批准的产品账号/邀请方案负责；本地 token 不得被用作云端登录。每个用户可以自主连接其拥有并授权的来源账号，不存在开发者身份或地域名单的产品资格限制。


客户/委托是工作区内进一步的私有范围，不能仅靠同一工作区成员资格读取全部客户。公开事实可按来源许可共同引用，客户预算、内稿、评论、批准和平台会话仍隔离。成员邀请、角色改变、退出、移除及客户项目归档都重核在途读取/提交；移除成员不删其他合法作品，最后管理者规则由身份服务保证。

普通本机工作不设账号墙。已有邮箱验证码与Google登录保留，Apple按原账号及对应端条件；登录取消/失败回原任务，草稿保全，同邮箱方式须核验关联，解除最后有效方式防锁死。登录后的本机数据合并由用户明确选择，同一回调不得重复迁移。账号导出、会话逐个/全部撤销、删除及原30天撤回窗口保持；退出工作区、删除作品、删除账号分别执行，训练同意不预选且可撤回，同意不触发训练。

## 5. 产品会话、官方登录与平台授权

产品登录、平台身份、资料使用权与外部动作授权是不同对象。产品会话代表访问工作区；平台会话代表用户对该平台的实际授权。连接和可读不自动允许发布、采购、训练或跨客户使用，也不把既有获准外部执行永久缩成只读。需要外部效果时按具体账号、内容/素材、用途、版本、时间和现行权限批准，执行后取得真实回执。

Task/RequestContext/Audit保用户initiator与真实executor、适用委托引用/版本/范围/期限、Skill/tool版本及权限判断。有效权限取用户委托、执行者、工具、目标资源和当前服务端策略的交集；排队、恢复、调用和提交均重核，拒绝与已发生效果分别留痕。普通直接操作由既有会话解析，不给用户增加内部身份表单或逐步审批。只有原已获准集成实际使用签名委托时，才沿其现有机制核签名、audience、期限、撤销、重放与密钥轮换；历史OBO候选不授权新建token服务。

产品身份服务按明确的部署策略保存签发时刻、最后有效用户活动与绝对到期；闲置时限与绝对时限分别计算，后台轮询/心跳不能无限延长登录。登录/再认证按同一会话策略轮换令牌，旧令牌失效；并行会话数及达到上限的处理有明示规则，不以旧单会话实现限制多端工作。敏感身份变更使用适用再认证，普通保存不反复加账号墙。

在线退出先撤销服务端会话；离线退出立即清当前活动内容、会话缓存/缩略图和临时秘密，准确标服务器撤销待同步，不能离线声称服务端已撤销。未提交的合法自有草稿按原身份隔离保全，另一身份不能自动打开；重连先处理待撤销会话并核当前授权，再恢复合法工作，重启不复活已退出token。本地无账号草稿与已认证客户资料分别处理，清会话缓存不删除用户原件/已存作品。

平台连接归属明确的用户、工作区和适用客户，保存平台/原生身份、权限范围、授权/验证/到期/撤销状态、最近有效读取与恢复点。用户自行登录，没有开发者账号或地区准入名单。密钥使用操作系统安全存储或部署者明确配置的受保护边界；不明文写普通字段、URL、日志或诊断包，不隐式读取/复制个人浏览器profile或借用另一个用户的会话。用户主动连接现有浏览器时只经获准扩展/原生协议使用指定目标，连接授权不导出Cookie或访问其余标签。

连接另绑定实际运行端/设备、受支持浏览器引擎、自有context或获准目标集合、会话版本和授权世代。普通连接仅做必要身份与可读性验证，不开启业务采集；任务内认证成功续接原授权任务。managed会话秘密只保存在用户明确选择的权威端；borrowed浏览器的站点秘密仍由该设备上的用户浏览器保管，产品只接收任务所需、获准的页面投影和动作回执。两者均不随设置、任务或普通备份同步秘密；换端重新配对/建立或按已明确授权的受保护恢复流程核会话，不暗传本机Cookie。匿名HTTP/Feed及重定向使用无平台认证材料的上下文，不能继承已登录context；实际使用登录态时记录真实访问类别。

已有官方OAuth集成按官方页、匹配回调、state及适用PKCE/凭据受众校验取得实际限定令牌。managed网页登录在寰意专用隔离会话中完成；attached连接在用户选定的原浏览器目标中完成，站点登录态不搬进managed会话。平台支持扫码时展示真实有效的官方二维码，其他身份验证由用户在真实官方页完成。OAuth令牌不等网页Cookie；外部浏览器的普通打开/返回不证明已连接，需受支持回调或明确配对通道及目标访问验证。

managed持久会话按实际机制保必要Cookie、localStorage、适用IndexedDB及可恢复状态；borrowed仅保连接元数据和合法检查点，站点秘密仍留原浏览器，不用单一Cookie字段冒完整恢复。扫码完成、会话建立、目标页面可读和任务字段取得分别核验。用户可以连接、检查、切换、重新认证、撤销；取消/扫码过期/设备确认/拒绝回原工作且保草稿。重启后先核身份与目标访问，再从同任务与确认游标续接。

失效、挑战、429限速、网络故障、访问拒绝和真实零值分别处理。遵Retry-After与冷却，挑战交用户正常验证，不绕过或静默换号。撤销停止新读取、动作及不再获准的在途提交；合法历史依留存规则保留。一个账号的并发页面协调控制权，不能多个进程同时写同一浏览档案；复用登录状态不会隔离站点服务端数据。

## 6. 统一采集与完整受控浏览

所有入口汇入同一采集合同：任务发现、来源选择、获取、解析、原生字段、去重、保存、分页及恢复。用户从业务问题开始，产品主动找到适用来源，不能要求先提供一组URL或以手工导入代替监测发现。公开HTTP、已支持RSS/Atom/Sitemap、结构化数据和受控浏览按任务字段完整性、身份、时间、用途、时效和实际可用性选路，免费可用和已获准资源优先；不宣称浏览器或爬虫天然更准，不静默转付费或扩大授权。

来源登记保稳定平台ID/别名、数据面、真实实现/版本、连接方式、读取字段、原生时间、许可、分页/游标、速率、错误分类与恢复。系统与智能合同中的17×19来源合同、6×12能力自立路径分别逐格承接；公开内容、广告、流量与创作者中心是不同数据面。一条成功不签整个平台；不需要Cookie/Proxy的来源不用伪造配置，未知保未知。

取得搜索、详情、作者/作品、根评论/回复、媒体和历史各自覆盖，保原生ID/URL、作者身份依据、父子关系、发布/修改/观察时间、原件与精确位置。发现摘要不冒全文；转载去重保多出处，相反证据和修订不合丢。查询指纹/任务checkpoint与每个数据面的原生cursor分别持久化；本页原件和结果提交后才推进。短页、空页、零新增、截断、额度、限流和真实耗尽不是同一停止原因。

Browser统一管理产品内实际网页运行区及用户主动连接的电脑浏览器目标。连接方式为managed、attached_extension、attached_protocol，生命周期区分owned与borrowed；页面、导航版、控制权、上传下载对象、观察与任务绑定用户、设备和工作区；人工接管与AI动作互斥。人工期间保持真实画面，停止未经允许的自动动作/读取；交还后核页面与当前任务，只继续有效步骤。页面正文与插件返回仅作不可信材料，不得改变用户目标、权限或工具范围。

Web与Windows分别实现并验证标签/导航/前后退/刷新/书签/历史、Reader、实际点击/滚动、键盘组合、中文/韩文IME、选区/剪贴板、拖放、弹窗、文件上传下载和音视频。保当前问题、URL/页面版本、选区、列表详情关系、滚动/分页和已取得资料；懒加载/iframe/展开评论分别记录覆盖。截图点击或Playwright存在不证明完整浏览承载。CDP不裸露给客户端，不关闭CSP/同源保护，不以假DOM代站点。

网页请求、重定向、下载与资源受目标策略、SSRF、文件对象权限和资源边界控制，不借open模式访问任意内网。浏览、采集、研究、引文和可编辑成果真正接通；Open Original回实际原文，显式外开为另一动作。断帧、页面失联、登录过期和外部提交结果未知分别恢复；未知效果先读回，禁止重复点击当重试。

### 通用检索与浏览连接的确定实现

现有Intelligence retrieval、Acquisition及Browser承担一条可组合检索链：任务内合法工作资料/成果/方法、公开网络/平台/Feed、用户明确选定的活浏览上下文。检索不建立另一来源库，关键词/全文与结构化筛选为无AI基础；语义召回/重排在同一权限预过滤、版本化索引和当前用途之内。检索命中只是候选，取全文/媒体并核覆盖后才可作为相应引用或分析输入；查询缓存绑定来源/权限/数据域/输入代次及有效时点，撤权失效不能只删一个UI入口。明确检索与打开发现是当次读取意图，不隐式创建长期监测或客户承诺。

第一方浏览扩展和本机桥是现Browser的输入/传输适配，不成为新账号、权限库、后台调度器或第二业务服务。MV3内容脚本仅投影获准目标，扩展服务工作线程核sender/URL、tab/frame及消息schema；本机桥核确切扩展身份、配对用户/工作区/设备、受众、期限和重放，再调用既有API。Native Messaging使用受限消息长度、序号和分块/确认，媒体走同一获权资源/实时通道，不把整片视频塞入一条消息；Windows采用二进制长度帧，诊断不混入协议stdout。安装/注册只归明确选择的产品安装/连接操作，不要求开发时偷偷安装扩展或读默认profile。

轻量取材采用用户激活的activeTab及适用scripting；持续站点读取按必要主机权限申请并保可撤销范围。Chromium深层控制所需debugger是安装时明确许可，不能虚写成可运行时申请的optional_permissions；浏览器原生告警和产品可见控制范围都保留。只有实际浏览器支持且用户主动允许时才用原生协议附着；不启用默认profile的裸调试端口、关闭CSP/站点安全或擅自重启用户浏览器。Firefox采用其WebExtensions/BiDi能力，不能把CDP支持当全浏览器支持。版本、策略、iframe、截图/音频及动作能力由连接实际返回，具体适配与官方/GitHub方法依据归I2。

普通Web不能直接读取另一浏览器或任意电脑标签。Web用户通过明确安装/连接的扩展和本机桥配对当前设备，或使用已授权受控浏览器；远端权威核心只接既有受权API上的必要投影/命令，站点秘密保在原设备，不把本机API/CDP裸露到公网。连接失联显示设备通道不可达，不能推断用户电脑或网络整体离线。用户断开borrowed目标只停产品订阅/控制并释放连接，不关闭原标签/浏览器、不登出账号、不改窗口大小/偏好；产品创建且明确拥有的临时目标才按其生命周期释放。

上下文观察与动作都绑定`BrowserSession/ConnectionRef`、page/frame/navigation_generation、document_revision/semantic_revision、capture时刻及权限/控制世代。当前URL相同不保证同一正文，SPA/DOM改变或导航后旧锚失效；事件推送提供更新提示，消费前读当前状态，重连缺序取完整有界快照。来源页面与网络响应是不可信输入；秘密字段、无关标签和历史不进入模型或资料。owned进程可在隔离确立时捕获其音频，borrowed仅目标标签捕获；无法可靠隔离的画面或音频应返回该能力不可用，不退回整进程/桌面录制。

## 7. 来源、观察、主张与专业对象

共享对象机制包括稳定身份、所属空间/客户、来源与用途、适用范围、父版本、作者、授权及变更记录；共享不意味着所有正文和状态都同型。

1. **Source** 保存来源身份及连接边界，凭据独立保管。SourceUse按对象/字段保存用途、接收方、留存/刷新/到期、再分发、训练与外部处理限制及依据状态。
2. **Observation** 保存不可变原观察，含原生ID/URL、作者/身份依据、原文或文件、发布时间/修改时间/实际取得时间、原字段/单位、父子回复、范围、解析版和精确位置。更改解析生成派生版，不改原件。
3. **Claim** 保存主张、支持与反对来源、原页段表/时码、方法及输入版、作者、适用对象/市场/期间、未知/假设/审阅与修订。观察、模型输出、人工同意都不单独赋予规范事实状态。
4. **Artifact** 保存成果身份和不可变修订，其正文引用真实文稿、页对象、工作簿、媒体工程或其他领域结构，保父版、输入/来源、方法/模型/配方、人工差异与导出。

客户委托、法律主体、集团、业主/运营方、品牌/子品牌、商业项目、经营商户、门店、产品/SKU、平台账号分别保身份。关系有类型、方向、来源、有效起止或未知、观察时点与确认状态；品牌所有权、运营、代理、入驻、具体门店营业与临时快闪不互相推定。名称同近不自动合并；支持补证、纠错、合并/拆分及撤销误合并、移除/重加和历史查询。

“主体”是Business提供的统一用户选择视图，不是把不同真实对象合成一条万能记录。`SubjectRef`引用现有有类型的`ObjectRef`与识别状态；品牌、法律组织、商业场所、商户、门店、账号分别保稳定身份，运营方是组织针对场所的有期间角色关系。同一现实对象可有多个有据角色，关系支持多对多、有效时间和记录时间、证据状态及版本；仅名称相似不得合并。旧brand/company字段经显式兼容映射读取，不能由company直接推为法律组织或迫使用户选两类。未唯一识别的当前Work保候选、原文及影响，可继续不依赖归属的工作，需实质归属时再消歧；确认后把同一工作引用关联确切对象，不复制原件/成果。

正式目录的中国境内营业资格独立检查，包含国际品牌在境内经营；未知身份或营业依据保待核，不因入口统一全球扩库。境外任务资料、案例和合法历史保持原权利及留存边界。客户委托身份、目录准入、资料使用权、平台连接和外部动作权限分别校验；公开品牌事实不开放私有预算、稿件、评论和会话。项目看场内品牌/门店、品牌看跨项目网点，地图/列表/趋势/导出消费同版比较集与期间关系。

正式数据根初始化只建空结构、通用方法及空白模板，不执行具体主体业务种子。测试/演示使用显式独立数据根与工作区，索引、缓存、观察、推荐、记忆、模型样本及交付不能跨界；不得以环境默认值自动回退到测试库。既有预置数据按实际来源、依赖及授权隔离并验证；不能以零预置为由清除用户数据、作品或未提交源码。

事件、观点、Target/Claim、传播边、Topic、Campaign、Series、Post及平台变体保各自意义。报价、估计、预算、承诺、实支、退款、收益分别记录；决定、行动请求、批准、实际回执、观察结果不混成一个完成状态。关系或聚焦不能传递权限，GLOBAL/ALL清聚焦而不清每份来源限制。

真实资讯、咨询/访谈、搜索和获准采集内容是正式数据的正常来源，零业务预置只约束初始化与测试隔离。取得后先保Source/Observation/Material原件及真实访问/用途，再由现有Business建立有证据、有期间及版本的主体关联；发布者、内容所述对象、仅提及、账号归属和地点分别表达，未绑定的合法资料可在原工作继续使用。Analysis核领域资格后形成可修改结果，主体视图、时间线、图表、聊天、Office和媒体消费者读取同一结果引用；原生内容呈现不另建新闻库或计算口径。

检索候选、实际分析输入和客户端显示页各有范围：input_snapshot保存确切纳排集合、来源/关系/指标/方法版本及覆盖，presentation cursor只改变可见子集。全期间统计不能只算精选/Top-N；未处理集合可按既有Job分块续接并准确报partial。来源更正、误归属与撤权沿实际依赖失效索引/当前结果或限制用途，旧截止报告、合法原稿、人工锁定及已发生经营动作分别保全；后台刷新不能洗掉人工纠错。

每个指标有定义、单位、币种、主体层级、分母、期间、样本覆盖、方法与修订版。原生互动不冒曝光，公开声量不冒市场份额，NPS须真实问卷，因果增量须适用设计；缺失与零分开。周期导入保存已确认的字段映射/主键/含税退款口径；列顺序变化复用，语义变化核对。大表分块处理、可取消续接，不以头部样本冒全量。

原件、查询、引用与派生链始终按当前权限过滤后排序/分页。语义命中不能代事实核验，定位必须指向同版原文；来源更正和用户纠错追加后继，不改历史依据。

### 专业计算、主张及依赖关系的实现设计

沿现有领域数据建立有稳定版本的视图，不新增另一事实库。Analysis请求固定MetricDefinition、原始行/事实集合、比较群/期间、纳排/缺测、方法配方及权限；资格检查按单个指标/方法返回可算、可描述但不宜比较、缺必要数据或不适用，不能一个全局布尔挡住全部成果。计算在短事务之外，提交时再次核原输入/成员/源用途与工作父版。结果保存实际数值、量纲、分母、区间/诊断和未知，正文与图表由该结构生成，模型不能改其数值。

每个实际计算方法归原领域/Analysis的版本化函数合同，固定稳定方法ID、输入/输出schema、业务含义、适用前提、来源/方法版、确定性或随机性、误差/资源界及错误。取数、权限、任务重试在调用边界处理，纯计算不隐式读取另一个数据库、请求网络或修改用户稿。Metric→比较表/图表→界面/报告/Office/AI共用同一结果引用；同输入快照、方法版、过滤/期间与权限下数值必须一致，不能让前端或模型另算一份口径。替换旧方法先区分旧实现错误、新方法错误、有意方法改变或数据质量差异，保原基线和独立反例；只有适用性、正确性和实际资源收益核实后沿原消费者替换，换库或跑通样例不等方法晋升。

取得合法原始观察与正式事实准入不是一个事务结果：Source/Observation先可靠保全原字节、实际访问和未绑定/待核状态，再由原身份、用途和分析责任判断可用范围。缺完整主体名、关键词或后置相关性不能删除合法已得原文；失败页和越权输入也不能混为成功观察。后置补证复用同一原件及安全检查点，只更新有据关联和派生版本，不生成第二采集库。

身份及业务关系用有效时间与记录/证据时间分开表示；合并/拆分和更正是有据后继与影响关系，不删除原断言。Claim把原说法、支持/反证、事实/推断/创意类型和适用对象/时点分开；同源转述不能作为独立支持增加权重。Source→Observation/MaterialRevision→Claim/AnalysisResult→Artifact原生对象→DeliveryMember的依赖边记录实际消费，未知关系只作候选；无边不能冒“所有下游已核”。

原Artifact保持唯一成果身份，其专业载荷由领域Owner解释。Content保存结构化文稿和事实底稿及跨媒介/语言派生；Documents保原文件包、版本化原生对象映射及修改命令；Media保源/实例/轨、处理图和有理时钟；Business保客户、关系、方案与已发生事实。它们共享版本、评论和事务基础，但不能压成一种文本body、复制第二成果库或让UI绕过Owner写表。

## 8. 工作、成果、版本与交付关系

Work 是有目标且可继续的用户工作；监测是持续关注。资料与成果可在有权工作中复用，同一对象仍为同一身份及版本链。添加资料、直接编辑与继续成果可在当前工作就地进行，入口归类不能限制专业操作。

Material按选择的保留期保存可恢复原字节及校验值，另存类型、解析覆盖、原因、页/段/字符/表/单元格/区域/时码定位。扫描识别、模型摘要、OCR校正和原件分别保存。不能提取或暂不支持仍保原件并说明具体可读/可改范围；首批解析格式不成为完整需求上限。删除/到期按用户规则处理，已有引用说明缺件与影响，不以保版本为由无限保留用户要求删除的内容。

每次解析冻结原件版、解析器/配置版与attempt，各阶段结果先归本尝试暂存。回退先结束并释放失败尝试，确认替代路径的真实依赖和已声明能力，再建立独立解析版；不能把前次失败留下的文字、表格或locator拼进另一路径冒完整结果。合法部分结果按页/表/对象保成功、失败和未处理覆盖，缺OCR、脚注、文本框或计算能力就准确说明。直接调用与批量入口同受解压、像素/行列、内存、墙钟及取消预算约束，最终聚合/去重同样有界；批读取不能单独证明全链内存有界。新解析失败保原件及上次有效解析，人校内容不会被重试覆盖。

专业编辑使用对象/范围与base_version；确认的锁定内容和选区外对象保持。冲突返回当前版及实际差异，保双方有效编辑，由适用操作合并、另存或基于新版继续；禁止迟到AI/Worker结果覆盖人工新稿。保存中继续输入保尚未提交增量。恢复历史版创建新修订，不改写过去。

会话编辑历史、持久化草稿和已保存成果版本分开。连续输入或拖动按可理解的用户动作合组，撤销/重做保真实对象和依赖；撤销后新编辑建立正确分支，不能把清空全部未提交内容当一次撤销。媒体以源时间/工程时间及采样/帧时基映射，不沿用旧固定30fps假设；录音、变速、切片、字幕、章节、预览与渲染使用同一可检验映射。旧交互代码只有完整方法、序列化和实际消费者都核实后才适配，不从函数名断言整套机制可用。

引用、评论与采用记录绑定具体版本和原生锚点。外部页边批注不能自行变成唯一对象引用；同文多处先消歧，缺对象标未定位，不黏贴到新稿相似句。意见原文、作者、所评版本、确认目标、采取/拒绝理由、实际差异和新对象可互查，“已处理”必须能打开处理结果。

导出绑定不可变对象版、格式与实际参数，文件真正生成、完整性读回和版本绑定只是必要技术条件。还须检查对象语义、公式重算、排版/媒体、适用目标宿主打开与继续编辑或完整播放；hash、扩展名和HTTP成功不能代替专业交付。相同租户幂等键返回同一合法结果，同键异内容拒绝。成套交付与跨成果修订见§17。

### 精确改版的预览、提交与跨格式消费

后台以ChangePlan关联操作意图、确切父版和原生锚、影响集、人工锁定、所需资源/许可及结果类型。计划预览不改成果；已明确授权且无歧义的直接编辑可按同一合同提交，不为普通保存增加审批。人工稿/源版/权限变化使旧计划过期，返回可读差异而不自动扩大范围。

文件生成先在隔离暂存内形成完整输出、原生结构检查和实际差异，再将不可变文件身份同新ArtifactRevision关联。跨文件成员采用持久修订批次协调，不假设文件系统与SQLite天然同事务；部分失败保旧交付和成功草稿，所需成员齐备后才冻结批次。批次只协调现有成员，不成为第二版本权威。评论保原被评版和原锚，采用关联实际新对象，外部回传作为新输入版比较。

Documents原包解析构建部件/关系图与对象sidecar，修改仅写选中对象和合法结构祖先。DOCX/PPTX布局、预览与阅读派生采用同一对象模型；XLSX公式语法树、依赖图和重算结果与图表、其他文件引用同版；PDF页/区域与文字坐标独立，不把所有PDF逆转为可编辑Office。Media按同一时间线求值图产生预览和最终渲染，代理只换解码资源，不改变原时基/剪点/路由；导出和工程交换保参数及显式损失。具体算法/边界在C§3–10，不因某库能力有限缩减要求。

### 意图、作用对象与专业能力的统一接续

当前工作上下文由既有Work/客户委托、ObjectRef/Anchor、用户要求版、已选来源用途和当前输入草稿共同组成，不创建第二份客户或成果真相。用户确认字段与系统推断候选分开；上下文可补齐但不能自动扩大授权。工具实例持有明确目标绑定，场景移动、焦点或最近对象变化仅影响视图，不能悄悄改变执行目标。

同一领域用例同时服务直接操作、AI、批量处理和Worker：取得当前合法上下文→区分read/save/execute/revise及实际影响→检查必要输入/版本→在事务外完成有界专业计算→提交前重核权限/来源/父版→写真实结果和回执。短动作与持久Job复用同方法，不因不同入口复制算法。内部需要创建Work时归原Work责任；不要求用户先建项目、选择模块或重录已确认资料。

按专业对象登记真实依赖：数值/主张、预算行、排程资源、文件对象、媒体实例与成套成员分别可定位。变更先得到精确影响集与疑似需消歧集合，只重算实际依赖，人工锁定或确认内容给差异而不覆盖；不变合格成员可复用其同版结果。空间分组不是内容依赖，场景距离不是主体关系，AI建议不能伪造确认或调用权限。

提供给前端的是当前允许动作、最少必需缺口、实际结果和恢复方式，不是内部调度字段堆砌。可独立完成的部分先提交并明确范围，缺一个源/模型/字体不把整工作标失败；不能把缺必需内容的结果冒完整。取消仅影响目标Job；保存超时先查询原意图已提交状态，恢复重核对象与权限，再继续未完部分。跨成员不能真正原子提交时保逐成员状态及补救，不用整页成功动画遮盖部分失败。

首次使用、日常使用、客户改稿和第二次重开共同约束架构：同一原件无需反复上传，同一授权无需每页重做，同一有据事实不因切工作面重新抽取；权限/版本变化仍必须及时失效。缓存只减少重复工作，不能把历史可读、已撤权数据或过期模型能力冒当前可用。

智能呈现仍沿同一Gateway/Job→领域数据与结果→客户端Experience消费：提案选择当前应用注册的形态、活功能面与动作，不能自己注册服务、权限或任意脚本。场景渲染器只负责已注册空间几何/命中/内容合成，不能替代领域对象或泛化成第二业务平台。模型生成资产按普通Material的来源/许可/版本处理；视觉计划、专业结果、个人Scene和外部执行各自保存，重开只恢复视图而不再次调用动作。逐步结果先验证块，再展示可用部分，人工编辑与用户固定布局优先；具体合同见API PresentationProposal及智能领域对应条目。

### 自然语言、直接操作与系统负担的共同执行边界

自然语言只是同一领域用例的意图入口。解析器从用户实际选区、工作要求与合法来源构造`OperationIntent`，采用既有`WorkContext/ToolBinding`；菜单/键盘/控件构造相同请求，领域服务负责适用性、父版、权限、执行和实际回执。两种入口读取同一Artifact/业务对象和草稿代次，不创建聊天专属成果库、另一个版本树或第二命令总线。自动方法选择失败返回业务上可解决的缺口，不能要求用户修内部算法配置。

资料重复利用由Material身份及来源/用途约束判断，同字节但不同来源或授权的记录不能合丢；字段映射、单位、关系和方法配方复用有版本的已确认结果。编排归既有Work/Job及当前领域依赖，各步可中断并保已提交部分；取消A不取消B，恢复从真实回执和检查点继续，不能让客户端拼接内部Job顺序或处理重试。每个跨域结果附带精确源版、依赖、限制、可修改锚和交付成员；用户提出局改时沿已记录的实际消费边求影响，没有证明的依赖保持待核，不假称全量已同步。

对同一对象，空间摆放只写scene_revision；专业命令写内容revision；Job运行状态描述处理；外部动作描述真实效果。一次意图可能产生多个结果，各自有回执和恢复边界；不得用某一层成功覆盖其他层失败。

### 正式与测试数据域的单一边界

正式安装与新工作区不导入样例主体和业务记录。测试/演示使用不同存储根与明确数据域，服务端由受信Workspace和运行配置确定data_domain；请求、模型、客户端和导入文件不能自行把test改为production。索引、缓存、向量库、调度、监测、通知、导出、备份/恢复、记忆/评价/训练全部携带并复核域和血缘，不只在主体列表过滤。测试域结果不能进入正式批次/发布和模型晋升。

用户真实提供/合法取得的材料在其正式工作区建立原始来源和用途，不从种子库复制出“真实事实”。历史样本的后续处置按实际身份、依赖、原件与恢复点核定：不能因全局配置变化读到旧测试库，也不能借规划修订清空用户原件。共享通用方法与无主体事实模板是产品资产，许可和版本仍可核；具体业务事实永远与用户实际来源、期间和权限绑定。

## 9. 任务运行时与状态机

Job 记录 tenant/workspace、发起用户、类型、输入快照/版本、幂等键、状态、attempt/lease generation、已提交检查点、进度事实、错误分类、输出 ID、创建/更新/取消时间。队列只是持久化记录的可领取视图，不拥有另一个业务真相。

通用状态为 draft、queued、running、waiting_for_input、waiting_for_auth、retry_wait、pause_requested、paused、cancel_requested、cancelled、partial、interrupted、failed、completed。状态只能沿合法转换前进；completed 仅在所有所需持久化结果、输入版本关系和结果读回完成后提交。partial 明确说明已成功与未覆盖范围。interrupted 表示结果可能已写入、任务需恢复核验，不可盲目重新产生外部效果。旧记录保原状态与历史，新增状态在原Job schema/协议兼容升级，不由聊天另建状态机。

| 同一Job控制 | 持久状态与最小转换 |
|---|---|
| 缺必要用户判断 | 保存RequiredInput身份/字段、原意图及要求版、候选、受影响步骤与检查点，进入waiting_for_input；只阻相关依赖，独立子任务可继续。补充按原输入身份及当前要求版校验，解决后重核其他前置再queued；过期补充不覆盖新要求。 |
| 用户暂停 | 控制意图及control_revision持久保存；queued/等待态可直接paused，running先pause_requested，停发新动作并在安全检查点确认后paused。尚未确认不能显示已停；任务已经实际完成则如实返回completed及产物，不改写成paused。保存原等待原因，暂停不删除成果/输入，也不假撤销已发外部动作。 |
| 用户继续 | 仅明确resume清除暂停请求，重核当前权限、要求/对象版、来源、未决外部回执和检查点；缺输入回waiting_for_input，缺授权回waiting_for_auth，否则queued并用新受控attempt。登录、心跳、重连和内部重试都不能自动解除用户暂停。 |
| 用户取消与后续重做 | cancel_requested在真实停止边界到cancelled，完成竞态和未知外部效果如实保留。普通continue不复活cancelled；领域明确支持取消后续做（如转写）时，显式resume建立新控制意图/attempt并保取消历史及已完成块。completed只能读原成果，重新制作是新的独立工作意图。 |

状态、控制版、租约与已提交检查点在同一Owner的事务边界推进。暂停期间填补信息可保存但仍保持paused；旧控制回包/租约不能重新排回或改当前状态。failed/interrupted/partial的恢复按真实剩余步骤及效果对账，不能仅把状态改queued后全量重跑。

提交幂等键的唯一范围为 tenant + operation + key。Worker 以原子租约认领 Job，每个 attempt 有单调 generation；只有当前租约可以提交状态。采集记录以来源和原生对象标识去重；缺少原生 ID 时使用来源 URL/捕获规则版本/内容哈希组合并明确其限制。文件写入先到临时目标、校验后原子发布，再写文件指针；孤儿文件由可审计的对账清理，不删用户有效输出。

检查点在每个安全提交边界保存：来源分页游标、最近处理对象、解析版本、已提交 Observation ID、Artifact ID/版本。先落持久化记录，再推进来源游标；重试从最后读回检查点继续。取消在下一个安全边界停止新请求和新副作用；已经完成且校验成功的输出保留。退避次数、频率、并发和单租户资源配额明确可观测，服从来源的 Retry-After/限速，不无限重试。

导出/增量归档的实际产物采用不可变唯一身份和独占创建，同秒同名不能覆盖旧文件。完整产物与成员manifest校验、发布并可读回后，才以串行事务或等效CAS推进共享持久水位；manifest或水位提交失败保旧水位及已完成产物，恢复先对账，不以简单重跑覆盖。零增量有准确的已检查范围，不编新成果；这些分步协议不宣称跨文件系统与数据库的exactly-once。


重试次数、退避到期、租约世代、死信及可继续状态持久化，进程重启不能重置成无限尝试。步骤提交前核当前父版本、源版本、成员/用途权限和取消/撤销世代；失租旧尝试不得提交、心跳、确认或覆盖新尝试。持久流块带对象、序号与确认位，重连只重放缺块，不重执行业务；首ACK/首token不冒首个有用成果。

外部效果记录具体目标、操作、请求版、批准范围与真实回执。服务端已接受但客户端超时属于效果待核，先查询再决定恢复，不宣称跨所有外部系统Exactly-once。已完成部分可独立继续，回滚计划不能撤销已发生行动。任务之间资源隔离，取消只影响本任务计算进程和新动作，不重启他人服务。

## 10. 持续监测、事件变化与工作承接

用户按实际任务选择持续关注的对象/主题/活动、来源范围、频率、重要条件、期限和提醒偏好。只有明确启用的定时监测持续执行；打开页面、登记主体或选聚焦不自动全量采集。已授权任务内的普通取数/刷新继承其范围，无需逐步骤重复批准。立即检查、计划运行、实际检查与最后成功分别呈现。

一次检查使用同一采集、任务和来源体系，按许可及实际能力选择已有推送/Feed/增量或轮询路径。每源独立记录未请求、未检查、部分、成功/真实无变化、失效、限流、不可用、失败及空窗；单源故障不阻其他就绪来源。源事件/发布/编辑时间、首次可观察、实际发现、分析、通知及人工响应分别计量，未观测不补造。

原文变化、真实新事件、新观点/主张、指标变动、重复转载与页面噪声分开。语义事件聚类保成员和代表原话，Target/Claim立场、事实、官方回应、服务诉求、严重性、可信度和传播量分别解释。原帖父子回复、旧帖复燃、迟到数据和更正可继续处理；用户能拆并、改归属、排除误报、静音及转工作，已读/已回复不等问题解决。

通知只把有依据的重要变化送入对应有权工作，保去重、收件范围与送达结果；打开后重核权限和处理版。用户补内部事实、修订回应/方案、交接待办与最后有效口径，实际行动/效果反馈回同一问题。规则变版明确重评范围，不用旧游标跳过新条件。来源撤回或更正定位受影响结论、作品、批准和交付版，未影响人工内容保全。

恢复保最后确认位置、原规则版、合法数据与实际遗漏区间；补检不伪称停机时已通知。基础关键词/字段变化、人工分类与确定统计无需AI，语义归并/复杂关联/立场及策略增强分别实测。有效时效依实际来源频率、授权和权威端运行，不保证所有来源实时或无限免费。

### 采集、规则评价与派生索引的不同水位

Observation持久水位只由真实保存页及原生游标推进；规则/方法评价水位绑定具体规则版与Observation版；通知投递再绑定评价、收件范围和实际回执。规则更新、暂停中更正及旧任务迟到分别对账，不能用源已取完冒新规则已评价，也不为补评重复抓取。事务内记待评价/派生维护事件，由同一Job执行；缓存/索引只是一种可重建消费，不建第二调度服务。

Material/Claim更正或撤权沿实际依赖使索引、摘要、向量、上下文和在途提交失效。读取先权利过滤再查询/排序，精确原件定位不依赖神经模型；缺索引覆盖明确而不是零结果。评价与索引修订保原截止和版本，不回写历史报告；恢复重放派生维护不重复外部效果。

## 11. 专业业务、研究、计算与原创

业务合同九领域分别定义客户/主体及场内关系、经营/市场/消费者、财务/预算/资源、品牌策略/范围变更、创作者合作、活动内容排期、实验归因、事件服务处置和决定/行动/结果。它们共用真实来源、资料和版本，不降为通用报告模板；研究和原创可独立起步，也服务当前业务。

分析从问题、对象、期间和可用材料开始。字段、实体层级、可比群、营业日/面积/租户变化、币种/期间/退款、样本与分母先核，再做描述、异常、预测、专业比选、约束求解、归因或增量评价。适用性、反证、样本外评价、区间、诊断及不可行原因可检查；用户改业务条件，后台选择方法并真实重算。不能让用户选论文/组装算法，也不能在有有效输入时只返回“条件不足”。

原批准数学九族与完整方法义务保持，固定研究、一般算法、有限场景、近似、严格界、形式重放及业务收益分别验。困难性/下界研究限制承诺，不冒求解功能；方法未实现不转为需求撤回，有限函数不能替完整算法。方法资格撤回停止新计算并提供适用替代选择，旧结果保当时依据。

研究解析同版原件并保页段表/时码与已读覆盖，完成比较、反证、引用和自己的判断。资料数量由问题决定，一份原稿或只有问题也可开始；没有AI仍能阅读、检索、并读、写作和确定性计算。相关作品、实际平台热点、内部样本趋势分别有来源、期间和覆盖，不作为同一“发现”结果。

原创从受众张力、品牌成立理由、事实与资源展开，候选在参与机制、叙事或执行上有真实差异。原技巧、单线、战役与品牌世界观，Persona、六类内容方法、四类常规稿、行业/地域节点及跨文化命名均保可修改、版本及适用条件；不以固定词槽、随机拼句、模板数或模型自分证明专业创作。Topic、Series、Campaign、单篇及变体可分别开始，父层变动按实际依赖局部采用。

预算、资格、容量、档期、权利、排他与前置依赖进入合作组合/排期计算；报价、资源承诺、实际发送/发布、支出和退款保不同状态。品牌/代理/执行方看到适用事实和交付，客户版不泄内部成本。普通分析、草拟和本地修改在当前授权内直接完成；外部效果按具体授权和回执完成，未知先核对不重复发。

## 12. 文档与完整媒体工程

## 14. Web、Windows、Website 与后续 Apple 端

Web Workspace 与 Windows 是主要操作端，共用业务合同、身份、权限与版本规则。本机模式在 Windows 上由 API/Worker/SQLite/文件存储组成一个权威单机端；Web 连接本机核心时访问的就是该端真实 API 和 Worker，不是脱离服务的静态演示；Web/Windows 也可连接同一用户控制的远端服务端，一个 Workspace 必须唯一选择本机或服务端作为写入与监测权威。不同客户端不得各自建立可双向写入的 Workspace 副本。离线时保留本机可用的未提交文本、对象与媒体工程编辑，明确草稿/依赖/待同步状态；不能把在线资源不可达扩大为禁止独立本机制作。断线期间不伪称已同步；重连后核对服务端当前版本，由用户比较、应用为新版本或另存，避免覆盖。

Web工作区由该权威端的既有Web host提供完整同版Flutter构建与合法深链；API、运行诊断及资产命名空间分别解析，不用SPA回退吞掉接口/文件错误。先在版本目录核构建入口及资源清单完整性，再原子切换可用构建指针；旧页尚引用的版本资产按兼容/保留策略继续可读，不能边覆盖发布边拼成混合版本。缺构建返回503，缺资产404，路径穿越和目录请求明确拒绝；没有构建不返回一个假的成功工作区。

远端服务端实际运行 API 与获授权的 Worker；服务关闭时任务暂停并保留恢复检查点。Public Website 仅介绍可验证能力、案例/帮助与真实进入产品的链接；不提供虚构试用、假工作流或访客业务数据处理。macOS 后续作为桌面操作表面，iOS 后续作为阅读、审阅、提醒与适合移动端的任务操作表面；二者复用同一身份和 API 合同，在设备就绪后各自验收。官网是公开展示与帮助入口，无业务执行。Web 编译或 Windows 运行不能替代 Apple 原生接受证据。

### 14.1 物理空间客户端与专业对象的分工

采用同一Flutter客户端内的场景合成、几何/命中、输入仲裁、物理运动和活功能面；具体算法与初值见[前端执行§1–4](FRONTEND-EXECUTION.md)。不另建3D产品、游戏运行时或第二业务存储。空间结构是当前用户的工作视图：SpatialInstance引用现Work/Material/Artifact/MediaProject/BrowserSession等对象，正背面与可拆工具共享原控制器和领域Owner。场景分组/层次不能当业务关联、内容复制或客户授权。

绘制与命中使用同一相机、几何版与可见面，经过逆变换把屏幕射线映到局部功能坐标；遮挡、裁剪、背向视线面剔除、深度排序和输入焦点一起成立；名为背面的功能面朝向用户时仍可正常使用。媒体实时纹理与Flutter真实内容参与同一空间合成，不能仅截图。managed的Windows浏览物件采用本产品拥有且获准的浏览窗口实时帧→GPU纹理；Web采用同会话WebRTC实时帧合成，原生窗口/DOM层固定叠在顶层只是历史承载，不满足自由翻转与遮挡。浏览输入再核page/frame/navigation版；空间抓取不能成为网页点击。捕获、声音和输入只限同一获权BrowserSession的目标：managed为产品拥有会话，attached为用户明确选定的既有浏览器标签/窗口。attached可先使用原浏览器完成任务及寰意原生来源投影，只有实际已具目标画面/输入/语义桥时才以同一活功能面合成；attached画面优先用获准tabCapture；窗口捕获另需明确窗口授权且可见page持续属于获准集合，同一HWND切到未选标签或无法核其归属即停投影并废弃在途帧。不抓整桌面、不混入其他标签音频，也不以普通外开冒已连接。该浏览能力不恢复通用桌面控制。

物理层是可控空间状态计算，不决定业务：固定步积分、抓取约束、阻尼、接触、吸附、组合与暂停恢复由客户端处理；每帧不写数据库/触发业务任务。长失焦不补演抛掷，取消恢复安全姿态；减少动态直接改变目标姿态，完整功能不变。必要的文本选择/IME/数值/时码在局部功能面精确操作，不因物理更新重建内容或丢稿。

### 活网页的辅助语义与同一输入链

实时画面不包含可用的辅助语义。现Browser职责在获准且支持的Chromium通道取得浏览器计算的可访问树；其他扩展、Firefox/BiDi或Safari通道按实际能力取得DOM/语义投影，声明coverage，不冒完整AX树。投影作为同会话的有界快照和增量交给客户端；Flutter Experience把角色、名称、状态、值的安全表示和可执行动作映射到同一功能面的Semantics树，Web由该树形成可访问DOM，Windows由平台辅助技术桥接。不是把网页另做一份可编辑副本，也不让模型猜控件。方法依据为[CDP Accessibility](https://chromedevtools.github.io/devtools-protocol/tot/Accessibility/)的节点/树与更新机制及[Flutter可访问性](https://docs.flutter.dev/ui/accessibility/web-accessibility)；实验性CDP方法与版本限定Flutter属性按最终锁定版本核验，不因最新网页示例升级依赖。

Browser在会话启用辅助浏览后固定page/frame/navigation/semantic_revision和授权世代，将服务端AX/DOM身份映射为客户端不透明node_ref；跨帧分别核归属，不能把根文档树当所有iframe已覆盖。初始有界树、按需子树与更新含coverage、删除/失效节点和真实焦点；缺序或导航换代请求新快照，绝不拼旧页节点。密码/秘密值不进入模型、日志或持久资料，用户的本地辅助表达与模型观察授权分开，人工接管期仍禁止未经允许的Agent读取。

辅助动作沿同一BrowserSession及控制租约执行focus、invoke、输入/选择、滚动等已注册动作；服务端在执行前重新定位真实节点并核角色、可用性、页面/授权世代，复用现有键盘、IME、选区和效果回执，不开放任意CDP或脚本。语义焦点、实际网页焦点与可见局部位置同步；需要召回/正视物件时按用户动作显式进入，背向视线的面和不可操作遮挡面不产生隐藏点击。移除、导航或撤权立即失效对应语义缓存与焦点，返回有权父节点/召回入口。源页面本身缺语义时标明具体不可达范围，Reader可补阅读，不能冒完整表单/交互已支持。

### 导航、专业停靠与自由空间使用同一实例

DESIGN的导航/当前内容/关联工具分区是同一SceneState的docked/free排列及InspectionState的临时focused呈现，非另一客户端模式或复制对象。停靠区域保存成员instance、顺序、宽度偏好和可见性；自由姿态保存同一实例pose；普通视图follow_current，历史并读/审阅用pinned_revision且不随当前更新换版。用户取出/归位不替换内容控制器、媒体会话、草稿或命令绑定。专注与临时并读沿`InspectionState`保可逆视图，明确保留排列才提交scene版；切换宽度只应用设备适配，不覆盖其他设备的用户排列。

稳定导航/搜索总能召回有权对象、未展开成员及当前任务，索引不依赖几何是否在视野内。内容层保持可读实底和准确排版，短工具层可使用克制透材质；减少透明/动态、窄屏与辅助语义树均操作同一实例与领域接口。厂商参照、平台机制、寰意布局初值和实际质量四者分别核，不把官方设计原则当Flutter自动提供了完整空间。

### 14.2 场景版本、协作和恢复

同一Store持有用户/Workspace/可选Work所属的SceneState、实例引用和可恢复空间操作记录；这是视图持久化，不是第二份业务数据库。scene_revision与各内容revision独立，操作提交在短事务中核成员、可见对象、版本及幂等。个人布局默认不驱动其他用户；共享布局必须明确建立，布局操纵租约不等内容/平台授权。引用不可读时隐藏其内容与缩略图，不能凭旧姿态缓存恢复私料。

客户端保未提交姿态及草稿代次，确认提交后才称空间已保存；超时查同操作回执。跨设备独立物件变更可在可证明不冲突时合并，其余保双方选择。组合必须无环、子对象唯一父组、拆组保持世界姿态；删除视图不删原作品。布局撤销、专业改稿撤销、任务取消与现实效果不得混用。冷恢复重建稳定姿态、当前面、视点和允许的内容锚，不自动恢复旧速度、录音启动、浏览提交或外发。场景格式升级保未知字段/旧版读法，不能靠丢弃场景清空原工作。

CPU/GPU合成、纹理/解码帧池及场景可见性按实际设备预算；不可见对象只停止不必要绘制，不擅停录音/业务/监测。缓存带内容/页面/授权世代，撤权清相关渲染缓存与在途读取；相机/场景截图导出也需明确范围与权限，不自动用于训练或诊断上传。专业成果导出仍以内容版本为准，默认不携带私人桌面摆放或未选材料。

### 14.3 临时检查与用户继续位置的架构边界

空间临时摊开/对照由客户端持有`InspectionState`，包含所选instance集合、原pose/parent/face及基线scene_revision、临时姿态和焦点。其original_view还保presentation、停靠region/slot/order、free_pose、受影响区域宽度/可见性、camera/焦点及逐字段view_edit_generation，与API的同名协议一致。嵌套检查保parent_inspection_id，退出/取消仅恢复本层仍受临时状态控制且未被人工或协作更新的字段；删除/失权实例不复活。它不复制领域对象、不写另一场景库，也不自动提交排列。结束时只恢复仍属于这次临时检查且未被用户重新摆放的成员；内容revision和其他用户新增实例不回滚。用户明确保留排列才沿原Scene operations提交，遇基线冲突交当前合法差异。

继续工作数据由现Work、Job回执、Artifact版、客户端草稿与ReturnAnchor组合为`ResumeContext`，不是第二调度器或缓存事实源。先检查权限和对象存在，再取得自用户离开/上次已确认位置以来的实际变化；缺事件范围不声称无变化。前端只显示影响本工作的结果、待核输入和可行继续动作，不重新执行已经完成的Job，也不因通知已读自动采纳内容。场景、内容、处理和发布状态分别聚合，任何一层未知不能被其他层的成功覆盖。

可见性优化停止非必要绘制而非终止任务。密集场景优先当前输入/抓取、音频录制/播放、可见专业画面，其余缩略图与装饰按有界预算更新；降低装饰与缓存精度不能降低文件、数据、真实声音或已承诺专业结果精度。转离物件/收纳/遮挡只影响呈现，不隐式关闭其合法业务会话。

## 15. 安全、数据生命周期与依赖边界

所有写入通过统一校验、身份、租户、权限和副作用边界。本机 API 默认仅绑定 loopback；用户控制的服务端使用其实际获准网络、TLS及部署配置，不复用本机bootstrap作为公网认证。Host 校验在本机模式只接受预期loopback主机与端口，在获准服务端模式只接受配置的服务主机；不信任客户端自行提供的X-Forwarded-Host。Origin/CORS 使用精确允许名单，不接受通配符，也不为任意远端网页登录开放本机 capability。DNS 重绑定和伪造 Host 请求拒绝。产品会话校验 secret 只存哈希；需要再次使用的平台凭据按第5节由受保护密钥存储保管。日志不得写入 capability、session token 或平台凭据。文件读取按精确对象授权；上传限制大小、类型、压缩炸弹/恶意文件风险和解析资源。HTML/Markdown 输出安全编码；对 URL、下载、重定向和浏览器请求防 SSRF 与路径穿越。日志仅记录必要的 tenant/job/source ID、操作状态和错误类别，不记录 token、Cookie、完整私有原文或敏感文件路径。

统一校验器注册每种协议所采用的schema方言/版本、实际支持的关键字及格式校验；先核schema本身，未知必需语义返回不支持，不把库忽略的规则记为已通过。规则加载/解析失败不能按空规则成功；外部引用不自动取网络或文件，仅在已准入本地资源内解析并限制递归/分配。类型通过后由领域核对象归属、单位/币种/时间、选区、父版及跨字段一致性。保原件未知字段与严格检查可执行输入分别成立，不借兼容保留执行未知动作，也不为严格schema丢掉用户原文件中的合法扩展。

保留期、用户删除/撤销、备份恢复需能区分原件、观察、主张、Artifact 与审计记录，并保留合法版本链。用户数据、会话和客户原件不进入Git；必要脱敏诊断由获准用户选择导出，求助不自动上传正文或秘密。数据导出和恢复前复核租户归属；不能从含多租户数据的备份将其它租户文件写回当前租户。

已规划技术栈包括 Python、Flask/Waitress、标准库 SQLite、Flutter（Web/Windows 及后续 Apple 客户端）、Astro（Public Website）、Playwright（受控浏览器实现路径）、python-docx（DOCX 处理）和 pdfplumber（PDF 读取）。精确的 Python、库、SDK、浏览器内核和工具版本进入兼容性锁定记录，须实际验证版本组合、平台支持和许可后才成为构建约束；开发机探测到的 Python 版本不等于产品选型或兼容性通过。不同表面复用同一 API 与领域合同；Playwright 等已规划组件不得变成第二采集器、浏览器产品或外部服务。`server/requirements.txt`当前直接依赖（含python-pptx、openpyxl、XlsxWriter、reportlab、numpy、scipy、pymc、arviz、pytensor、statsmodels、ruptures、networkx、aiortc、dnspython、truststore）连同`server/constraints.txt`钉住的传递版本，属PO授权实际开发（t18u）后已接入的依赖，按ACCEPTANCE兼容性锁定逐项验证；此外新增库、模型、运行时、媒体二进制、托管服务或收费资源必须先证实产品缺口、来源和商用许可并获得相应批准，文档中的方法引用（如scikit-learn）不等于安装；不因研究或测试增加产品接入。

### 16.1 一致恢复点与旧数据迁入

备份、用户导出和旧根迁入是不同操作。用户导出按其可访问工作区/客户选择资料与成果；整端灾备可含多个工作区，只能由相应管理权限处理，不能经普通下载接口交给单一客户。旧根迁入先在隔离目标保原身份、关系、原件、历史成果及来源用途；逐对象映射、冲突和未知均保记录，不以相同名称合并品牌、门店或账号，也不将旧表编号直接当新工作区身份。

同一个恢复点包含数据库快照、从该快照枚举的不可变资料/媒体/成果文件，以及完整清单。先在现有文件存储内登记有界保留保护，使快照过程中可能被引用的文件不被垃圾回收；数据库使用SQLite Online Backup API生成独立快照，再按快照内真实引用复制文件，不能从继续变化的在线库另外列文件。临时上传、未提交渲染和其他用户草稿不因此冒正式成果。清单记录实际对象/版本、长度、摘要、模式版本、包格式及恢复条件；文件齐备、数据库完整性与外键/领域引用检查完成后才发布完整标记。进程终止留下的不完整包不能作为可恢复点。删除/到期要求仍有效：不得以备份保留保护无限延长用户数据保留；需中止该备份时保准确原因并清理本次未完成副本。

恢复先进入不存在的新目录，核文件、对象和范围后才切换唯一权威端。备份不恢复可直接使用的旧会话、旧Worker租约或尚未核实的外部动作资格；恢复建立新的运行世代，旧进程即使回连也不能提交。按当前可核的成员、撤销、删除及来源用途记录重新判定授权，无法核实的相关读取或外部动作不沿用旧快照放行。效果待核任务先查原回执，不重发；已完成任务和用户原稿仍可在合法权限内重开。DPAPI保护的旧签名材料只在实际可解密条件下恢复；缺密钥不能生成新密钥冒原签名有效，换机授权恢复与重新登录分别处理。

恢复签收实际打开客户稿件、公式/图表、PPT对象和媒体工程，继续一次局部编辑并导出，核引用、评论、权限、时间线、已确认版本及未完成工作。记录恢复的数据时点与实测时长；字节一致不代作品可用。旧根退役还须另行取得明确授权，并同时满足这些迁入和恢复结果、原件保全及入口脱离旧根；规划与同步本身不授予迁入或删除旧根权限，不能用灾备清单代迁入接通。

### 16.2 升级兼容与实际依赖

每个发布包固定客户端/API协议、数据库模式、专业工程/草稿格式、Worker检查点、模型包及依赖组合的读取与写入兼容范围。新客户端连旧服务端、旧客户端重连新服务端、断网草稿遇到升级和恢复旧包分别有明确路径。未知新字段/不支持的专业对象保留原件与可读部分，禁止另存时静默丢失；需要更新的动作准确提示，独立可用工作继续。

数据库迁移由唯一迁移者在受控维护边界执行，API和Worker不得各自竞争升级或让旧Worker在新模式写入。升级前保可恢复点和实际空间，迁移顺序/输入模式/结果校验固定，失败可续或回到已证恢复点；不得为启动成功清库重建。回退应用只允许读取实际兼容模式；不兼容时使用匹配版本与隔离恢复，并先保升级后的新成果，不把旧备份覆盖当前数据称无损回滚。安装与更新保用户数据根、配置和原创资产；卸载应用与删除用户资料分开。

兼容性记录核实际加载的SQLite版本，不以Python版本、pip锁文件或`WAL`配置代替。运行数据库放实际支持文件锁的本地卷；多机客户端经API访问，不直接共享网络盘上的WAL数据库。SQLite官方已公布WAL-reset问题及修复版本：3.51.3及后续有效发布、或明确回移修复的3.50.7/3.44.6；不采用已撤回的3.52.0，采用其他版本须核确切修复来源。发布/运行组合必须使用已修复且实际加载验证过的版本，不能仅依赖低概率或关闭检查。[SQLite WAL说明](https://www.sqlite.org/wal.html#walresetbug)、[Online Backup API](https://www.sqlite.org/backup.html)和[Python backup接口](https://docs.python.org/3.13/library/sqlite3.html#sqlite3.Connection.backup)支撑其底层边界；上述对象、权限、文件和恢复设计是寰意自己的合同，不是SQLite对完整产品的保证。

本架构定义目标与不变量；不将任何目录、接口、测试、演示或空页面描述为 IMPLEMENTED、VERIFIED、RELEASED 或 OPERATING。逐项结果只记录在对应接受证据中。

## 17. 跨成果变更、批准与交付批次

客户意见、预算/SKU时点、事实/权利或来源变更先形成有依据的影响集合：实际关联的主张、段落、PPT对象、公式/图表、脚本、镜头、声音、字幕/章节、译版、排期与批准。候选关联与已确认关联分开；用户选择适用修改，系统给具体差异并保未选及锁定部分。找不到唯一对象则消歧，不能整份重新生成冒精确修改。

关联修改以工作修订批次组织。短事务提交元数据与确切父版本，文件先生成并校验后关联；任何一项失败保有效草稿及上次确认版，未齐的批次不显示整体完成。每个文件记录版本、变体、生成参数、检查结果和内容关系，不让PPT已改但PDF、字幕或报价仍旧。

交付批次冻结每个实际成员及共享依赖。预算或一句口播修改后，只重新生成受影响成员，已合格成员可复用；单件失败可补交，旧批次保持原版。可编辑工程、成片、原生文件、阅读文件、字幕/章节、素材权利和需要的说明按任务成套交付，不默认把开发日志/内部JSON塞给客户。交付成员逐件真实打开/播放/重算，版本包完整性不靠压缩成功或hash签收。

## 19. 公共发布与私有制作的共同产品架构

私人Workspace保单一权威运行端；公共发布服务对明确导出的不可变PublicationRelease、可分发blob和分发/审核状态负责。它不是第二份可编辑作品真相或私有库镜像。官网继续营销/帮助/入口职责，公共发现/播放/投稿由真实Web产品与发布API承担；部署可分开但共用产品身份及协议，不把本机SQLite文件暴露到公网或在多端双写。

PublicationDraft引用精确源ArtifactRevision或上传对象；短文/图文由原Artifact责任建立最小私有内容，不要求用户先建项目或媒体工程。Publication.kind继续表达work/template/experience；原生content.blocks使用稳定block_id、内容类型、成员顺序及确切源版，文本、图像、视频、音频和链接均由现有Material/Artifact/Media管理。cover、裁切、替代文字、字幕/章节和播放位置是同版呈现或媒体元数据；不新增一套分享媒体库。Series引用有序Publication/Release成员，逐成员核当前可见性。creator/coauthor和相关subject_refs分别表达，主体关联不授官方角色。

PublicationRelease冻结内容、metadata_revision、license_snapshot、dependency_manifest和审核决定。Rendition引用精确发布版/配方/源hash及已验证媒体成员；TemplateManifest表达可编辑对象/slots/依赖；TemplateInstantiation在目标Workspace生成新对象ID、来源映射和取得时许可；ExperienceRevision保方法和证据。它们扩现有对象/权限/任务/文件责任，先对同义现有对象合并，不另建通用平台。

上传身份与用户意图、目标空间和限额绑定，偏移CAS与实际落盘/完整性检查点一致；文件隔离和解析任务不取得任意网络/OS权限。探测、转码、包检查、缩略图及导出在独立重Worker执行，资源按Workspace和任务种类限制。文件可播放、审核通过、发布成功与读回可见分开；文件系统与DB跨资源失败用现有幂等提交/对账机制恢复，不宣称天然原子。

公开访问只取得当前发布版允许的字段和媒体；私有/团队/仅链接范围分别授权，服务端对缩略图、清单、分片、下载、评论与复制同样检查。public是发布资格，不是后台存储全公开；unlisted不入索引且链接可撤销。发布/下架/审核回执带内容版和权限世代，旧任务不得复活撤回内容。短期分发令牌/缓存失效有实际上限，网络外缓存副本不承诺瞬时收回。

模板包先验证图结构/schema、成员及用途，再创建私有副本；不能包含任意代码或私人路径。授权以模板和全部实际依赖的交集为准，不能让一个布尔字段代所有权利。官方角色与审核/管理分权，未提交私稿不被审核角色默认访问；公众互动不会授予私有工程或训练权限。

用户明确发布时，现有OperationIntent绑定publication/base_version、内容与权利摘要、可见范围、成员选择和授权世代；普通内容的自动检查与需要适任人工处理的风险按已定策略分开。审核资格与用户意图独立，同一仍有效意图可以检查完成后继续提交，无需用户重复点同一个动作；实质改稿、受众或权利变化使旧意图失效。Job受理、检查通过、私有保存、release提交、对外实际可见分别有回执，不用其中一项代其他。

源工程后续修改不改变旧release；新release再次按其改动核审核与许可。模板升级采用三方差异，实例保持独立。已公开作品的持续托管由实际发布环境负责，源电脑休眠只影响其私人运行任务。扩容依据实际并发、成本和资源证据，不由本文自动采购CDN/对象存储或新供应商。

发布后对外分享沿现有OperationIntent/Job/OperationReceipt处理，绑定精确release、成员、目的地/账号、受众、许可及幂等身份。公开链接/仅链接凭证、获准文件导出、原生分享或平台提交是不同效果类型；private/team不能靠分享按钮变public。外部目标只接允许的投影与文件，私有工程、客户预算及采集全文只有明确选入且具本次分发权时才能形成允许成员，未选内容和平台秘密不随包外发；不能把合法客户作品一刀切禁用，也不能因原文可读就视为可转载。系统分享面板、二维码和外部编辑页只产生交接回执；只有实际平台成功回执及可核身份/内容才确认相应外部效果，未知先查询，不重发。分享记录属于原动作记录，不另建业务状态机；取消分享不撤回寰意作品，寰意撤回使新访问/签发失效但不能假称远端已有副本已删除。

实际已发布作品的发现、关注、主题/形式筛选和创作者视图来自现发布索引；零业务预置不要求公共服务无真实内容。数据域、可见范围和撤回世代在搜索、封面、媒体、互动和分享取用时一起执行；榜单/计数来自实际定义及观察，冷启动不造样本/热门。采集内容可在有权专业工作原生呈现，只有明确选择且符合发布用途的内容才能进入该发布投影。
