## 1. 原创方向：作品成为空间，专业工具随意图展开

把寰意做成有编辑品位、内容张力和专业精度的智能空间，不做普通管理后台，不做聊天窗口合集，也不做“暗色播放器＋模板卡片”的网站换皮。

同一视觉语言按三类真实工作组织内容，专业差异由对象和操作决定：

| 语言及用途 | 具体构图与视觉决定 | 不能牺牲的操作 |
|---|---|---|
| 作品展映：发现、作品与官网叙事 | 用真正作品的画幅、色彩和内容构成主次；大幅焦点与紧凑作品索引有疏密对比，标题、作者和用途形成杂志式编辑节奏；媒体背景可从作品提取受限色域，但正文/控件有稳定对比 | 不靠自动播放音频、无限滚动诱导或3D环绕拖慢找作品；提供明确列表/搜索、暂停、继续及返回 |
| 关系折页：研究、方案、来源与修改 | 当前成果是稳定主面；点击出处、预算或意见时，相关对象沿真实关系展开为可并读层；分支只来自真实候选/版本，不画装饰图谱 | 原文和编辑位置、权限、人工稿不丢；可固定并读、收回、键盘到达；不能每次操作都弹出浮窗 |
| 媒体精细制作与文件交付 | 视频/播客保真实画面、时间线/波形和精细工具；文档文件按预览/意见/下载组织 | 媒体专业精度保留；不再把用户变成Office排版与网格操作者 |

以上是执行方向，不是新增用户术语或三个产品入口。主负责人将三者做成同一套对象连续、字体、焦点与返回语言；不用让用户选择设计流派。先完成跨工作面的构图和原创资产，再提炼组件，不能先套组件库再为内容找位置。

满天星Logo及Pim兰花、Bram彼岸花、Ness椰子树、Jas葡萄、Aris茉莉花保持身份。探索枝叶负形、细密分枝、光与纸面层次、作品到工作面的连续展开；不把角色当五个模型/导航，不用满屏植物装饰代专业感。品牌图形可有表现力，界面文字仍清晰。客户成品遵其品牌与许可，不强加寰意图案。

不继承被否定样稿的固定色板。由主负责人围绕展映、密集研究和专业编辑建立一套实际内容下的统一方案，只对真实未决的关键构图比较备选；不强制先做两套完整设计或全量Figma才允许实现。设计决定随实际组件和用户操作核验回写，不能只换颜色或以模型自评分签审美。

## 2. 每一工作面先建立“内容—行为—状态”合同

逐项从现行领域合同取得用户起点、输入、完整专业处理、可编辑输出、对象/父版、来源/许可、手动路径、AI增强、失败和恢复。形成同一设计资料中的页面条目，不新增产品编号体系。

每条必须有：进入方式；当前真实主对象；主要直接操作；按需工具；有权的来源/评论；loading/empty/partial/error/conflict/ready；本机草稿/服务端已保存/已发布区别；返回锚；键盘与窄屏路径；实际API/领域消费者和验证步骤。尚无接口时标设计夹具，不能用静态成功页面替代接通。

| 工作面 | 必做的内容构图和操作 | 关联与退出条件 |
|---|---|---|
| 私人工作首页 | 有内容优先呈现真实作品与继续点；无内容用简洁可操作的打开文件、空白作品、描述目标；紧凑呈现待修意见，不做KPI墙 | 目标委托进入真实处理，草稿只保存；四组织入口保留且当前工作内可就地操作 |
| 客户与主体、经营比较 | brand/company及商户门店关系可发现；同期间表格/趋势/地图按问题组合；预算情景可直接改输入并检查约束 | 无坐标仍可列表操作；未知不当0；客户私域、来源口径和返回比较集保持 |
| 品牌/策略/合作 | 展示机制不同的方案，不强制三档卡；正文、预算、客户意见按需并读；合作提交与排期有真实对象 | 已批准内容锁定，客户改一处生成准确影响与差异，不重造全案 |
| 监测 | 事件/时间/来源组成主视图，区分原事件、新事实、更正、重复及未查；重要性有理由 | 选信号查原文，再进实际工作；停机空窗/失权不伪装无变化 |
| 研究/文档文件 | 原文、真实生成文件、引用与意见可并读或专注查看 | 用户提供修改意见，系统生成改版；保原稿/未选内容和来源，不构建完整Office编辑器 |
| PPT/工作簿/动态HTML | 实际页面、表图及HTML交互预览，清楚给出下载和修改意见入口 | 系统承担排版、计算、局部改版与文件交付，预览不冒已导出或已发布 |
| 视频 | 实际素材、源/时间线预览、多轨、字幕、合成、颜色和音频；选择后工具跟随 | 播放头、源时钟、锁轨、代理状态、撤销组和工程版保持 |
| 播客 | 选题/前采可独立进入；录音电平、take、词稿、波形、混音和章节相互定位 | 校正文字与改音频不同；试听不提交；设备失败保录音与工程 |
| 作品发现与详情 | 公共发现围绕作品编排，标真实作者/官方身份；详情以播放器为主，模板和方法为关联层 | 标题/封面/许可/状态可读；暂停、seek、字幕、音轨、续播、队列与返回成立 |
| 模板详情与复用 | 展示真实可编辑对象、替换槽、依赖、许可及效果；预览与编辑权不同 | 使用模板生成私有副本，映射源版，新ID与父版可核；源作者改版不能覆盖用户稿 |
| 经验与创作者 | 将问题、作品/版本、方法、步骤、条件、反例与实际结果组织为可读内容；创作者主页真实分组 | 能转为带出处的工作方法；收藏/复用不冒专业验证或训练授权 |
| 发布工作台及审阅 | 上传、解析、处理、提交、审核、发布、撤回分别呈现；原作品/发布版差异可查 | 默认私有；只导出被选择的可分发成员，不让客户预算/评论/会话进入公共版 |
| 成套交付/设置/恢复 | 成员版本、意见、修改和补交清楚；连接、备份及授权以用户可理解后果呈现 | 部分成功不全绿；恢复不重放外部效果；失败保有效作品 |

## 3. 逐步执行：每步有具体产物，不交空建议

### 步骤1：锁住范围、参考与被否定方向

读取最新直接要求、DESIGN、领域合同、实际消费者和素材归档映射。线上main、`D:\寰意`候选、旧路径只读资产分账；不凭路径或旧阅读记录认定已研究。将每个拟采用参考的完整相关动作、原帧/音轨、图表及出处实际核到；记录用户问题、观察、可提炼原理、不可复制资产和本产品应用。尚未完成的研究继续执行，不用计数或自动解码代人工设计结论。缺失材料由官方/作者源码/专业原文补研，记录替代依据，不让用户重找。

产物：在现有体验研究/保全记录中更新具体采用与否定，标明本次视觉样稿拒绝。退出：负责该构图/操作的参考有实际解释，无“照着某视频做”这种无法执行的指令；这不额外要求重审已有效的全仓证据。

### 步骤2：把工作连续性画成可操作关系

按上一节建立各工作面内容与状态；明确公共内容空间、私有专业空间、营销官网三种职责。公共/私有切换保原客户、草稿和位置，不给每种专业功能新增一级导航。画出“作品→模板→我的工程→精修→交付/发布→返回”的真实路径，以及研究引用、经营监测和客户修改路径。

产物：有对象/状态/权限的文字线框和操作流，不套统一三栏。退出：入口、返回、取消、权限失效和第二次使用都有落点；一份资料或空白作品能直接开始，不被样例数量卡住。

### 步骤3：原创视觉研究并收敛

用同一套真实且获准内容落实展映、关系并读、精密编辑，不仅设计欢迎页。按当前ChatGPT/Apple/One UI参照校准画幅、信息密度、字级、内容与控件分层及品牌识别；必要的备选只用于解决具体取舍，不另开长期设计研究。主负责人以实际操作与清晰可达的成品判断收敛，组件默认样式不替设计。

产物：选定的跨场景视觉方案和不采用方向说明，记录未定项；不把未审核建议称已获PO视觉接受。退出：不同专业工作能一眼区分且共用身份语言，删掉Logo仍有一致的排版/比例/动效特征，不能只靠装饰颜色辨认。

### 步骤4：完成品牌、令牌与可访问资产

在现有原创资产责任内制作满天星的小尺寸/单色/浅深底形态、五植物的静态与短动作源稿、彩色入口识别与中性线性动作图标。字体保授权和真实字形；建立surface/text/action/focus/status等语义令牌，禁止按域把整页涂成固定颜色。密度、字号、对比、缩放、减少动态与不透明退化一起验证，保客户作品原风格。

产物：可编辑源资产、导出规范、语义token及实际组件状态，先改现有`theme.dart`/`brand_art.dart`/`plant_guide.dart`职责，不复制旧皮肤。退出：真实多语长文本和密集表/时间线可读，角色可关闭，品牌源资产与生成尺寸可追溯。

### 步骤5：制作动效分镜和可中断原型

对每个关键动作写：前态、用户触发、同一对象、起止几何/内容、焦点、期间可操作项、完成来源、中断反向、减少动态、失败回退。按第4节先做可中断原型，不以渲染视频代真实交互。输入、选区、播放头和数值先即时响应；长任务进度只用真实阶段/数量。

产物：同一版本的动作参数、事件夹具、原生交互原型及正常/快速反向/减弱动态录像。退出：动画未结束时仍能继续操作，不丢草稿、不因快速切换显示错对象，减弱动态能完成同一任务。参数来自实际测量与主负责人审阅，不从参考倍速猜生产速度。

### 步骤6：在现有Flutter外壳实现基础行为

先读取`app/lib/src/app.dart`、`workspace_shell.dart`、`controller.dart`、`api.dart`和`models.dart`真实方法。在原职责内实现统一对象路由、返回锚、冻结提交、同请求读回、焦点/IME/草稿保全；大控件按实际职责拆分而非先建空目录。显示状态带来源：后端、用户编辑、前端派生或设计夹具；所有夹具明显隔离。

产物：一个可以直接打开、编辑、离开并回来的真实工作路径及相应测试。退出：响应丢失不重做、迟到返回不盖新稿、切客户不串稿；不是仅有导航和空页面。用行为测试复用正确控制器，不恢复被否定页面。

### 步骤7：接公共作品、模板、经验与私人制作

按PRODUCT-SPEC内容生态章节和API合同完成发布身份、真实文件上传、处理、审核、发布快照及各可见范围；接播放器、作品详情、模板兼容预检、私有复制和经验编辑。公开视频详情和模板详情有不同构图；“使用模板”按类型进入文档生成/预览/意见改版或完整媒体编辑；必须生成独立私有版本，不只生成标题列表。

产物：用户和官方两类投稿流程、两种模板的真实复用、经验及返回链。退出：原作者作品不被改，平台身份不可伪造；无权限、素材缺失、包失败、下架、续传和源版更新都有正确可继续动作；私人预算及评论不公开。

### 步骤8：完整实现各专业工作面

以原领域合同为范围：客户主体、经营地图/比较、预算策略/合作、监测、研究/Word/PDF、PPT、工作簿、视频、播客、客户修订分别接真实模型及专业操作。输入范围按现行合同与当前后端核定，已修旧问题不重复当成待办，前后端消费者保持一致；Work创建、保存草稿、执行委托保持区别。前端与后端依赖可并行，不等所有服务完成再画界面。

产物：每个工作面可操作的真实对象、对应正/负向测试及作品；不能以一个通用编辑框计多个专业领域完成。退出：参数、选区、引用、人工锁定、原生导出、独立重开和异常恢复按领域成立；按实际依赖分批不削全产品范围。

### 步骤9：官网与多表面适配

官网使用原创叙事展示真实作品和软件动作，提供可核版本与真实入口，不借假上传/生成装成应用；公共内容浏览与发布入口进入实际Web产品路由。Web/Windows分别测实际媒体、文件、键盘、IME与系统权限。320/390窄屏和200%缩放下重新安排工具，不把桌面整体缩小；三种界面语言与专业语言任务分别测试。

产物：独立官网构图与实际工作区、各表面完整流程。退出：不同屏宽仍能到所有操作；二维专业区域可适用横向滚动但正文不溢出，客户作品与平台品牌不互相污染。

### 步骤10：真实接口、性能和失败体验验收

对同版客户端/API/Worker/数据根核身份，使用合法真实作品和隔离测试数据。分别测输入到首个可见反馈、连续操作帧时间、播放/seek、首个有用结果及完整交付，不把动画或缓存命中当业务完成速度。覆盖断网、保存冲突、撤权、素材失链、磁盘满、取消、迟到结果和冷启动；记录实际结果和失败证据。

产物：同版操作录屏、对象差异、真实导出/重开、性能分布与恢复回执。退出：未知不当0，部分不全绿，未选内容和人工稿不丢；键盘、焦点、字幕、非拖拽和减少动态实际成立。结构测试、视觉观察、运行和专业质量分别签。

### 步骤11：成套审核并收尾

把完整工作面、关键动效、密集/空/异常/窄屏状态、品牌资产和真实用户成果组织为一套可审阅结果；主负责人先完成一致性与专业审阅，再交PO。用户此前否定的设计不能作为对照中默认正确的一方。把未通过之处修到对应合同，不靠新增规则、删能力或只改首页应付。

产物：同版设计源稿、实际应用、必要演示和验收记录；正式开发按分支→检查→PR→门禁→合并→读回。退出：PO视觉意见逐项落实、真实业务验收完成后才称相应范围交付；规划同步和文档CI通过不代此步骤。

| 场景 | 对象连续与视觉动作 | 工程状态、打断及验法 |
|---|---|---|
| 作品展映进入播放 | 封面自身扩展为同作品播放面，背景收束，控制层后置出现 | 先固定release/cover身份；播放器准备状态独立；失败保封面与重试，不能用转场结束触发假播放；快速返回恢复原列表位置 |
| 模板看效果再看结构 | 同模板在成片预览与可编辑结构之间切换，替换槽通过选中对象出现 | 预览不自动下载原工程；复制成功读回后进入私有新ID；缺依赖就地标注且保已选材料 |
| 引用与关系折页 | 当前正文不漂移，来源沿真实锚展开为并读；关闭回到原选区 | 不重建文本控制器/IME组合，不失焦；原文不可读不冒空正文；并读宽度可调并有键盘等价 |
| 进入精修 | 文件的指定页/区域进入核对与修改意见，媒体镜头进入精修工具，内容正视，其他工具退后 | 选区与父版先到位；动画可打断，拖动/录制/播放时不因新建议重排；媒体对象不重新下载再播放 |
| 调整导出条件 | 在同一工程就地展开格式、尺寸、时基、声音及交付成员，主要动作与参数顺序稳定；桌面与窄屏按可用空间安排 | 保选区/播放头/草稿；取消不启动输出，明确导出后冻结所选版本。生成期间继续编辑不改变在途输出；估算与实际大小分开，快速开关/减少动态/参数不支持仍能返回继续工作 |
| 客户修改影响 | 确定影响对象依次可检查，疑似关联有独立标记；应用后用真实差异解释变化 | 预览不写作品；冲突保双稿；多成员失败只回退可回退部分并明确持久结果，不靠整页淡入冒一致完成 |
| 保存与任务反馈 | 状态靠近正在改的对象；真实回执后轻量变化，后台任务不占满屏 | 请求受理、处理中、已保存、已发布不同；未保存新输入继续保留；无总量不画伪百分比 |
| 品牌生命感 | 满天星分枝/植物的短动作回应明确进入或用户邀请，休止不持续吸引注意 | 不演AI人格或情绪来证明正确；错误不卖萌，静音/关闭装饰后全部能力保留；离屏停止非必要绘制 |

动效数值在试作时按用途和距离测定；原90ms只是首次可见反馈目标，不给所有转场套90ms。可用短、中、空间转换三个时长语义token，记录实际范围和设备；超长任务不通过动画拖延输入。默认不自动播放声音，不做抢滚动、视差强绑定和必须观看的开场。 reduced-motion是现行产品要求；WCAG 2.3.3本身属AAA，不能误报为AA新增门槛。

## 6. 最终核查与官方依据

原26领域、专业数学、全部用户操作、无AI基础/AI增强、Web/Windows/官网与后置设备的原要求仍有效。新增内容生态依SPEC和API进入同一系统，不用几个上传/模板页面替全产品完成。

官方资料用于确认机制和适用边界，实际API必须与项目锁定SDK版本核对，不因研究链接自动升级依赖：
- Flutter动画概览：https://docs.flutter.dev/ui/animations/overview 。用状态、controller及局部重建实现可中断行为，不用框架默认动画作设计。
- Flutter AnimationBehavior：https://api.flutter.dev/flutter/animation/AnimationBehavior.html 与 MediaQueryData.disableAnimations：https://api.flutter.dev/flutter/widgets/MediaQueryData/disableAnimations.html 。区分平台减少动态标志和应用偏好，应用自有动画逐项实现退化，不假定只改MediaQuery就控制全部框架动画。
- WCAG 2.2：https://www.w3.org/TR/WCAG22/ 。适用AA沿现有合同执行，目标尺寸含其明确例外；减少动态作为既有产品义务，不把AAA准则错误标AA。
- WAI交互动画解释：https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions 。装饰动画可关闭，必要媒体预览与实际编辑仍保留。

这些依据不证明设计好看、用户任务成立或全部可访问性合格。必须用以上步骤形成实际作品、交互、性能与PO审核结果。
